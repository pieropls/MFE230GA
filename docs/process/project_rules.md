## Non-negotiables
1. **The sealed result stands as reported.**
   - Primary A3 (Sonnet study): test Sharpe −0.58, verdict "Do not implement".
   - No other number is presented as if it passed that holdout.
2. **Every result carries exactly one label.**
   - CONFIRMATORY: the frozen study.
   - POST-HOC: chosen after seeing the data.
   - FORWARD TEST: frozen before new data exists.
   - In LaTeX, put `\tagc`, `\tagp` or `\tagf` in every table and figure caption.
3. **Post-hoc specs are written to a file and SHA-256-hashed before they run.**
   - Every pre-declared variant is reported, whatever its result.
   - Never iterate on test results.
   - Count every look when deflating Sharpe ratios.
4. **Every number in the report has a `% src: <file>` comment.** Wrap unverified numbers in `\prov{}`.
5. **Never invent** transcripts, team critiques, citations or individual contributions. Use `\todo{}` instead.
6. **If a gate fails, stop.** Write what failed to `analysis/output/STOP.md` and do not work around it.

## Code layout (Piero's convention: small, flat, readable)
- **`analysis/params.py`**: dates, lags, paths, portfolio parameters and the variant definitions.
- **`analysis/data.py`**: loaders, group returns, signals and portfolio/backtest logic.
- **`analysis/stats.py`**: IC, Newey–West t, Sharpe, drawdown, factor regressions, placebo and deflated Sharpe.
- **`analysis/plots.py`**: every figure.
- **`analysis/run.ipynb`** orchestrates everything top to bottom:
  - Title cell: `---` / `### Title` / `---`.
  - Each section is a markdown cell: `---`, then `##### Section name`, then one plain line of explanation, followed by its code cells.
  - The first section is `##### Imports`.
- No classes unless unavoidable, no extra layers, no scaffolding. Existing `french.py`, `signals.py` and `diagnostics.py` may be folded in.

## Figures (do not deviate)
- Python and matplotlib, **default matplotlib fonts**: no Computer Modern, no custom fonts, no `usetex`.
- **Bold titles** (`fontweight='bold'`), minimal formatting, light grid at most, no chart junk.
- Colours: `#1F4E79` for confirmatory, `#B35C00` for post-hoc, `#2E7D32` for forward test, greys for everything else.
- Save as vector PDF to `report/figures/`, sized for a 6.5in full-width or 3.2in half-width slot so text stays readable.
- Every figure is regenerated by one notebook run.

## Writing style for the report
- Plain, precise English for a finance professor. Lead each subsection with the finding, then the evidence.
- Use "we". Define every acronym at first use. Write equations for the signals, models and portfolio.
- It must not read as AI-written:
  - Avoid "delve", "crucial", "landscape", "robust" (except as a statistical term), "notably", "furthermore" chains, and triplet lists for rhythm.
  - Use em dashes sparingly.
  - Never write a bold "Answer:" label.
- Banned in the main text (appendix only, if at all): "sealed capability", "transport attestation", "amendment chain", "technical restart", "within-run diagnostics". Do not use A0–A4, F1–F5 or G1–G5 without a legend.
- Page budget:
  - Executive summary: 1 paragraph of at most 230 words.
  - Section 2: at most 5 pages.
  - Section 3: at most 4 pages.
  - Main body: at most 10 pages.
  - Appendices: free.
